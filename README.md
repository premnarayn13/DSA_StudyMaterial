A complete, production-grade repository for mastering Data Structures & Algorithms. Includes an interactive problem progress tracker, 30 deep-dive handbook chapters, and a curated list of 539 problems combining **Striver's A2Z DSA Sheet** and the **GFG 450** problem set.

🌐 **Live Web Application:** [https://premnarayn13.github.io/DSA_StudyMaterial/](https://premnarayn13.github.io/DSA_StudyMaterial/)

---

## 🌟 Repository Features

### 1. 🎯 Interactive Problem Tracker (Web App)
- **539 Curated DSA Problems** across 20 structured modules.
- **Direct Practice Links:** Instant access to LeetCode, GeeksforGeeks, and TakeUForward problems.
- **Offline & Persistent Progress:** Marked problems and stars are stored locally in your browser (`localStorage`).
- **Instant Search & Multi-Filters:** Filter by topic, difficulty (Easy, Medium, Hard), platform, and completion status.
- **Keyboard Shortcuts:** `/` for search, `j`/`k` for navigation, `s` to toggle solved, and `Esc` to clear.
- **Dark & Light Mode:** Seamless theme switching with system preference detection.

### 2. 📚 Complete DSA Handbook (30 Chapters, 397 Sections)
Comprehensive written guides with asymptotic proofs, memory representation layouts, code implementations, edge-case analysis, and interview patterns.

### 3. 📊 Practice Tracking Spreadsheet
Includes [`MY_GFG-450.xlsx`](./MY_GFG-450.xlsx) for offline milestone and revision tracking.

## 🚀 GitHub Pages Hosting

The interactive tracker is hosted via **GitHub Pages**.

### Accessing the Live App
- **URL:** [https://premnarayn13.github.io/DSA_StudyMaterial/](https://premnarayn13.github.io/DSA_StudyMaterial/)

### Automated Deployment
- A GitHub Actions workflow is located at [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml).
- Whenever changes are pushed to `master`, GitHub Actions automatically validates dataset integrity, verifies statistics, stamps asset versions for cache prevention, and deploys the latest build to GitHub Pages.

## 🛠️ Local Development & Preview

To preview the tracker locally:
```bash
# Clone the repository
git clone https://github.com/premnarayn13/DSA_StudyMaterial.git
cd DSA_StudyMaterial

# Start any static file server
python -m http.server 8000
```
Open [http://localhost:8000/Problems_List/site/](http://localhost:8000/Problems_List/site/) in your browser.
